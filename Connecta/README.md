# Connecta

**Connecta** es una aplicación que conecta personas con oportunidades de voluntariado ofrecidas por ONG, fundaciones y grupos sociales.

## Tecnologías
- Backend: .NET 9 (C#)
- Frontend: Flutter
- Base de datos: PostgreSQL

## Objetivo
Facilitar la participación ciudadana y el registro verificable de horas de voluntariado.

## Equipo
Proyecto desarrollado por estudiantes de Ingeniería Industrial y de Sistemas (UPSA).
